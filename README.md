# Menu Platform MVP

A polished Arabic/English digital menu MVP for local cafes and restaurants.

## Current MVP
- Responsive customer-facing menu
- Arabic/English toggle
- Category navigation
- Product search
- Availability status
- Google Maps / Instagram / WhatsApp buttons
- Lightweight admin dashboard
- Product CRUD in browser localStorage

## Production roadmap
1. Connect Supabase PostgreSQL + Storage.
2. Add authentication and tenant isolation.
3. Add restaurant/branch management.
4. Add QR generation per branch.
5. Add custom-domain/subdomain routing.
6. Deploy to Vercel and connect the owner's domain.
7. Add analytics, orders, table ordering and payments as paid features.

## Important
The Oaza data is a demonstration dataset for a portfolio prototype. It is not an Oaza client project unless the business explicitly approves the work.
